# Backend Documentation

## Overview

The backend is built using FastAPI and is responsible for:

- Handling API requests from the frontend
- Processing user questions
- Extracting and embedding PDF content
- Storing and retrieving embeddings from the database

The backend is built using FastAPI and is responsible for handling API requests, processing user questions, extracting and embedding PDF content, and storing embeddings in the database.

The backend architecture is modular and organized into routers, controllers, utilities, and configuration files.
